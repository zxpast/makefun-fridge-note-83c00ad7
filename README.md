One funny passive-aggressive note a smart fridge leaves for its owner:

> I noticed you opened me at 2 a.m. again. The ice maker saw everything, and it tells the yogurt.

The joke is the fridge as a smug witness: its sensors saw the midnight raid, and the punchline turns the appliances into gossips. The twist lands in the last words — the ice maker tells the yogurt.

## Run it

```sh
node main.ts
```

`main.ts` writes the single line to `/output/entry.txt`. Node 22 standard library only, fully deterministic: the same bytes on every run, no network, no clock, no randomness.
